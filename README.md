## Quick Start

### Prerequisites
- **Python 3.7+** (for Python scripts)
- **Java 8+** (for Java programs)
- **Git** (for version control)

### Clone the Repository
```bash
git clone https://github.com/SamikshaRani/Core-Learning.git
cd Core-Learning
```

### Run Individual Scripts

**Python:**
```bash
cd Python-Basics
python goal_tracker.py
```

**Java:**
```bash
cd Java-Basics/code_practice
javac Main.java
java Main
```

## 📈 Git Commit Philosophy

This repository follows **conventional commits** for clear and organized history:

| Type | Description | Example |
|------|-------------|---------|
| **feat** | New features or scripts | `feat: add goal tracking functionality` |
| **docs** | Documentation updates | `docs: complete chapter on control flow` |
| **style** | Structure/organization changes | `style: reorganize Python scripts folder` |
| **fix** | Bug fixes | `fix: correct calculation in calculator.py` |
| **refactor** | Code improvement | `refactor: simplify goal_tracker logic` |
